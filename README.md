A program that copies a joyful image — a laughing child and a golden retriever puppy chasing soap bubbles in golden-hour light — to /output/entry.png for make.fun's ai-happy-01 bounty. The program then verifies the copy: it must be a whole PNG or JPEG (checked by its first bytes) and within the 1 MiB cap, and it exits with an error otherwise. The copy is byte-for-byte deterministic, so both grader runs write the same bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
